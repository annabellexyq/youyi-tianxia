# 游医天下 · 2D 白描山水叙事版

白描水墨风格的网页叙事游戏。上帝视角「天下疫图」点击解锁**九境**，每境以中医
「**五脏五色**」组方（肝青 / 心赤 / 脾黄 / 肺白 / 肾黑），演绎不同的空间、服化与命运。
明清之交、瘟疫流行的虚构故事，内容为虚构，如有雷同纯属巧合。

## 运行

直接用浏览器打开 `index.html` 即可；或起一个本地静态服务器：

```bash
cd youyi-tianxia
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

## 文件结构

| 文件 | 作用 |
|------|------|
| `index.html` | 入口与界面屏（标题 / 地图 / 场景 / 组方 / 对话） |
| `game.js`    | 主逻辑：地图解锁、场景切换、组方判定 |
| `art.js`     | 白描美术渲染 |
| `data.js`    | 九境 / 五脏五色 / 世界模型数据 |
| `styles.css` | 白描样式 |

## 玩法

- 「天下疫图」上帝视角，循河而上，九境次第解锁。
- 每境拟方，按与经方的契合度判定 **上工 / 中工 / 下工**，影响空间、服化与剧情。
- 内容为虚构，如有雷同纯属巧合。
